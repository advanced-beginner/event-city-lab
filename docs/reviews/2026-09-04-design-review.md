# Event City Lab 디자인 검토 (2026-09-04)

기준: `main` `22455eb`. production 빌드를 Chromium으로 1280×720 / 1440×900 / 1920×1080에서 18장 캡처해 DESIGN.md 계약과 대조했다. 캡처 PNG는 저장소에 넣지 않았다. 수치는 CSS module을 grep으로 직접 센 값과 레이아웃 계산값이며, 대비는 WCAG 2.x 상대 휘도 공식으로 계산했다.

결론 한 줄: 도시는 강하고, 크롬은 약하다. 골든아워 픽셀 도시와 표지판 언어는 이 제품만의 얼굴인데, 그 얼굴이 레터박스에 갇혀 작게 보이고, 주위 UI는 어느 대시보드에나 붙일 수 있는 부품으로 채워졌으며, 글자 대부분이 계약(본문 14–15px)의 절반 크기다. 고칠 순서는 읽히게 → 가리지 않게 → 조용하게 → 하나로다.

## 지킬 것

- 골든아워 등각 픽셀 도시 두 장.
- SVG 안의 표지판 언어: 크림 보드 `#fff5d9`와 `#302840` 2px 외곽선, 상태 램프.
- 상태를 색·램프·문구로 중복 표현하는 규칙.
- 타임라인의 번호. 이벤트는 실제 순서다.
- 좌 설정 · 중앙 도시 · 우 증거의 삼열과 로그·분석·비교 세 관점.

## 방향

두 방향은 같은 바닥(글자 크기, 대비, 레터박스, 단일 셸)을 깔고 크롬이 도시의 언어를 얼마나 빌리는가에서 갈린다.

### A. 관제 데스크 (추천)

도시만 말한다. 크롬은 도시의 크림 지면과 픽셀 외곽선의 잉크색을 빌린 종이 한 장이고, 표지판 언어는 도시 바로 아래 "지금 일어난 일" 판 한 곳에만 쓴다. 행동 버튼 하나만 노란 밴의 색이다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| paper | `#f7f1e3` | 캔버스 (도시 지면 `#f4eddf`에서) |
| board | `#fffaf0` | 패널 · 판 |
| ink | `#302840` | 글자 · 외곽선 (픽셀 outline과 동일) |
| ink-2 | `#5f6675` | 보조 글자 (paper 위 5.2:1) |
| action | `#f4c445` | 실행 버튼 하나 (ink 글자 8.5:1) |
| line | `#d9d0bd` | 경계 |

의미색 red/green/violet은 계약대로 유지하고 시설·경로·배지·상태 문구에만 쓴다. 글꼴 제안: IBM Plex Sans KR 400/600 + IBM Plex Mono 400, 다섯 단계 12/14/16/20/26, 한글 본문 행간 1.55. Nanum Gothic을 유지해도 크기 체계만 적용하면 진단 1은 닫힌다.

레이아웃: 중앙 폭을 이미지 비율에서 계산하고 남는 폭은 증거 패널로. "지금 일어난 일" 판은 도시 아래 46px 고정. 좌 패널은 실행 버튼을 바닥에. 빈 상태는 "첫 메시지를 보내면 여기에 쌓입니다 R". 도시 안 시설 표지는 HTML 오버레이 또는 atlas 24px 이상.

원칙: 도시만 말한다 · 글자는 계약대로 · 눈썹 라벨·라벨용 mono·장식 그라디언트·배지형 상태 제거 · 표지판 언어는 한 곳에만.

계약 변경: DESIGN.md 색 토큰 값, 글꼴 조항(선택), 레이아웃 조항(중앙 열 폭 규칙). 글꼴을 바꾸면 THIRD_PARTY_NOTICES.md 갱신.

### B. 야드 표지판 (대담한 대안)

규칙 하나: 표지판이면 조작할 수 있다. 버튼·탭·타임라인 노드·시설 표지는 크림 보드와 2px 잉크 외곽선, `0 3px 0` 그림자의 표지판이고 패널은 테두리 없는 지면이다. 색은 `palette.json`의 ground `#f4eddf`, sign `#fff5d9`, outline `#302840`, amber `#ffd45e`, coral `#e86b4f`, green `#5f9f43`. 본문은 Nanum Gothic, 제목과 표지판 글자에만 Do Hyeon(18px 이상).

위험: 조작 요소가 모두 두꺼운 외곽선을 가지면 밀도 높은 우측 패널이 무겁고 장난감처럼 보일 수 있다.

## 두 방향이 공유하는 바닥

- 글자 크기 바닥 12px, 본문 14px. 이미지 안 표지는 화면 기준 11px 이상.
- 보조 글자색은 토큰 하나. 직접 쓴 hex 색 147종을 토큰으로 치환.
- 중앙 열 폭을 이미지 비율에서 계산해 레터박스 제거. `CityWorld`의 `preserveAspectRatio` prop이 `<svg>`에도 닿게.
- 현재 사건 판은 이미지 아래 고정.
- 셸 하나. 헤더·미션·재생 조작·푸터·열 폭이 두 화면에서 같다.
- OS 모션 줄임을 두 화면 모두 JS에서 반영.
- 오류 표지 폭은 글자 길이에서 계산.
- 빈 상태는 다음 행동을 말한다.

## 자기 비평

- A의 크림 지면은 생성형 디자인의 흔한 기본값에 가깝다. 남긴 이유는 그것이 이 도시의 실제 지면색이라는 점이고, 세리프와 테라코타를 버리고 잉크를 `#302840`으로, 강조를 밴의 노란색으로 잡아 갈라섰다.
- 어두운 관제실(검정 + 형광 강조)은 버렸다. 밝고 실제 도시처럼 보이라는 계약과 반대다.
- 신문 조판(헤어라인, radius 0, 촘촘한 칸)도 버렸다. B의 radius 0은 픽셀 표지판에서 왔고 선이 2px다.
- B는 대담함을 여러 곳에 쓰므로 추천하지 않되, "표지판 = 조작 가능" 규칙은 A의 한 곳에 빌려 왔다.
